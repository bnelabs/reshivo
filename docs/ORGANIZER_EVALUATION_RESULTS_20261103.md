# Desk organizer decision journey — results

**The app's recorded calculations were useful, but this run did not establish a reliable end-to-end AI workflow or an overall advantage over ordinary Meta.** The [preregistered protocol](ORGANIZER_EVALUATION_20261103.md) and [synthetic fixture](../examples/organizer-fixture-20261103.json) were run against frozen commit `ee6062e99263fec08a3cbadf4935826c24d39658`. This is one developer-operated, synthetic case checked by a separate software reviewer; it is not an independent human user study or evidence of physical product performance.

The ordinary baseline completed four first-attempt requests and each parsed response reported `muse-spark-1.3-contributor`. The app displayed that configured model, but its raw provider requests, returned model fields, response bodies and usage were not captured. The two visible connection errors do not establish whether Meta or another connection component caused them. No failed app request was retried within the run. The baseline's first answer was lengthy and included irrelevant material; the app's final no-winner explanation was shorter but contained the context issues above.
